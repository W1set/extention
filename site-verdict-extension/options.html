Настройки Site Verdict

Без ключа расширение всё равно покажет дату регистрации домена и эвристику по бренду, но не сможет запросить репутацию у VirusTotal. Бесплатный ключ можно получить на virustotal.com после регистрации (раздел API Key в профиле).

Эти домены добавятся к встроенному списку известных сайтов для проверки на тайпсквоттинг.
